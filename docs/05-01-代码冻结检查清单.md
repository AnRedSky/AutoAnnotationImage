### 5. 本轮修复的关键问题

| # | 问题 | 修复 |
|---|---|---|
| 1 | 307 重定向：`POST /api/datasets` 命中 `POST /` | `redirect_slashes=False` + 改 `@router.post("")` |
| 2 | `Dataset.task_type` 字段缺失 | 在 ORM 模型新增 `task_type: Enum('classification','detection','segmentation')` |
| 3 | `GET /{dataset_id}` 和 `DELETE /{dataset_id}` 缺失 | 在 dataset.py 补全两个端点 |
| 4 | `BigInteger` 主键在 SQLite 测试环境不兼容 | 全部改为 `Integer`（同时修 FK 引用） |
| 5 | Celery `DisabledBackend` 触发 `AttributeError` | `get_progress` 加三层 try/except 兜底 |
| 6 | 前端 `npm install` 可能因网络慢失败 | 已用现有 node_modules 完成构建验证 |
| 7 | `docker-compose.yml` 与 `.env` 端口不一致 | 新建 `.env.docker`，compose 引用之；改用服务名通信 |
