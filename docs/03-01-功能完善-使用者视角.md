# 系统功能完善 - 系统 4.5 章节配套

---

## Why

W2 已完成 FastAPI + Vue 3 的基础骨架（42 API + 7 页面），能跑通核心流程。但从**文档使用者视角**审视时发现 3 个具体问题：

1. **图片上传多张时，无法查看到文件上传的队列**：缺上传进度可视化（哪些文件正在上传/已完成/失败/大小/速度/剩余时间）
2. **数据集无法查看已上传的图片内容**：数据集详情页应能查看图片列表（缩略图、文件名、大小、状态）
3. **数据集无法查看图片标注情况**：每张图片的标注框、类别、置信度

同时按"使用者观点"审视后发现还有这些未完善：

- 训练任务没有"详情"和"取消"按钮，无法查看失败原因或中止长时间训练
- 删除图片时 Dataset 计数没有正确回退（且与 SQLite 兼容性不好）
- 前端 HTTP 客户端没有 timeout 配置，长请求会无限等待
- 文件下载（导出 COCO/YOLO/CSV）走的是 `<a>` 标签，携带 token 不便

## What Changes

- **前端补全**：上传队列组件、标注查看器、数据集详情页、训练任务详情/取消
- **后端补全**：图片详情、批量删除、文件二进制流、缩略图、训练任务详情/取消/错误查询
- **SQL 兼容性修复**：用 SQLAlchemy `case` 替代 MySQL 专属的 `GREATEST`
- **回归测试**：新增 16 条测试覆盖新端点，全部通过
- **前端构建修复**：类型标注 + 缺失图标

### 1. 图片 API（`app/api/image.py`）

| 端点 | 方法 | 功能 | 关键字段 |
|---|---|---|---|
| `/api/images/upload/{ds_id}` | POST | 批量上传 + SHA-256 去重 | `total/uploaded/duplicates/items` |
| `/api/images/auto-label/{ds_id}` | POST | AI 预标注 | `total/auto_labeled/need_human/avg_confidence` |
| `/api/images/list/{ds_id}` | GET | 分页 + 状态过滤 | `total/page/page_size/items` |
| `/api/images/{id}` | GET | **单图详情** | `id/dataset_id/filename/status/ai_prediction/final_label/annotation_history` |
| `/api/images/{id}` | DELETE | 单图删除 | `success/deleted_id` |
| `/api/images/batch-delete` | POST | **批量删除** | `success/deleted/missing` |

**关键改进**：将 `func.greatest(Dataset.image_count - 1, 0)` 替换为 SQLAlchemy `case` 表达式：

```python
from sqlalchemy import case
new_img_count = case(
    (Dataset.image_count - 1 < 0, 0),
    else_=Dataset.image_count - 1,
)
await db.execute(
    update(Dataset).where(Dataset.id == dataset_id).values(image_count=new_img_count)
)
```

> **为什么**：`GREATEST` 是 MySQL/PostgreSQL 函数，SQLite 不支持，会在 pytest（`aiosqlite` 内存库）下抛 `no such function: greatest`。

## 前端实现细节

### 1. `UploadQueue.vue`（新组件）

**位置**：`frontend/src/components/UploadQueue.vue`

**核心功能**：

- **拖拽上传**：`@dragover.prevent @drop="onDrop"`
- **逐张串行上传**：`for (item in queue) await uploadOne(item)`，避免后端过载
- **实时进度**：`axios.onUploadProgress` → `item.loaded/total` → `el-progress`
- **瞬时速度估算**：`item.speed = (loaded - lastLoaded) / dt`，> 200ms 一次更新
- **剩余时间**：`eta = (total - loaded) / speed`
- **状态机**：`pending → uploading → done / failed / duplicate`
- **失败重试**：单条重试 + 一键重试全部失败
- **SHA-256 去重反馈**：后端返回 `items[i].duplicate = true` → UI 显示"重复"黄色 tag
- **空状态**：`el-empty` 引导用户拖拽

**Props**：`datasetId: number | null, autoStart?: boolean`
**Events**：`@uploaded(result)` 全部完成后触发

**关键代码片段**：

```typescript
async function uploadOne(item: QueueItem) {
  item.status = 'uploading'
  let lastLoaded = 0, lastTs = Date.now()
  const fd = new FormData()
  fd.append('files', item.file)
  try {
    const res: any = await imageApi.upload(props.datasetId!, fd, (e) => {
      item.loaded = e.loaded
      const now = Date.now()
      const dt = (now - lastTs) / 1000
      if (dt > 0.2) {
        item.speed = (e.loaded - lastLoaded) / dt
        lastLoaded = e.loaded
        lastTs = now
      }
    })
    if (res?.items?.[0]?.duplicate) {
      item.status = 'duplicate'
    } else {
      item.status = 'done'
      item.loaded = item.total
    }
  } catch (e: any) {
    item.status = 'failed'
    item.errorMsg = e?.response?.data?.detail || e?.message
  }
}
```

### 2. `AnnotationViewer.vue`（新组件）

**位置**：`frontend/src/components/AnnotationViewer.vue`

**核心功能**：

- **大图预览**：原图 460px 宽
- **元信息**：文件名、尺寸、大小、状态 badge、标注时间
- **最终类别**：`el-tag` 显示当前 `final_label.name`
- **AI Top-5 候选**：每条带 `el-progress` 置信度条 + 颜色编码（≥80% 绿、≥50% 橙、否则灰）
- **快捷确认/强制采用**：每条候选下两个按钮
  - "确认"：写入 `is_confirm=true`
  - "强制采用"：写入 `is_confirm=false`（即使 AI top-1 是 cat，强制选 dog 也算修正）
- **其他类别下拉**：`el-select filterable`，选择后立即以 `is_confirm=false` 保存
- **标注历史**：`el-timeline` 倒序展示 20 条，含 from→to 类别 + 耗时
- **计时**：组件挂载时 `startTs = Date.now()`，保存时 `cost = Date.now() - startTs`

**Props**：`imageId: number, editable?: boolean, readonly?: boolean`
**Events**：`@saved(info)` / `@closed()`
