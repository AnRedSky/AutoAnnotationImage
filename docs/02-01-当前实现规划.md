## 二、技术决策记录

### 2.1 前后端分离

- **决策**：后端 FastAPI + 前端 Vue 3 SPA
- **理由**：后端算力重（PyTorch 训练）、前端交互重（标注 + 训练曲线图表），解耦后可独立部署
- **接口**：RESTful + Bearer Token，跨域由 Vite 代理解决

### 2.2 前端选型变化历史

| 阶段 | 选型 | 备注 |
|---|---|---|
| 初始 | Vue 3 + Element Plus | 旧版本 |
| W1 | 改为 **React 18 + Ant Design 5** | 老师希望"主流"框架 |
| W2 | 改回 **Vue 3 + Element Plus** | 最终定稿（用户决定） |

> ⚠️ **关键约定**：系统对应章节技术基础表描述的是 **Vue 3**（最终版），不要写 React。

### 2.3 后端 uv 化

- **决策**：用 `uv` 管理 Python 依赖，**不写入系统文档**
- **保留**：`requirements.txt`（Docker 用）+ `Dockerfile`
- **文档描述**：仅说"使用 pip 安装依赖"

### 2.4 ML 库

- **决策**：`timm`（预训练模型） + PyTorch 2.2 + torchvision
- **预训练模型候选**：ResNet50 / EfficientNet-B0 / ConvNeXt-Tiny
- **训练优化**：AdamW + CosineAnnealing + 早停（可选）
