## 一、目标与边界

### 1.1 目标
将当前可工作的 MVP 团队管理模块升级为企业级团队协作模块，具备：
- 完整 CRUD（增/删/改/查 + 所有权流转）
- 完整审计追溯（11 个写操作全部入 audit_log）
- 与数据集/标注/统计三大模块深度集成
- 安全加固（最后一名 manager 保护 / 二次确认 / 频率限制）
- 良好 UX（分页/搜索/批量/可视化）

### 1.2 边界
- **不包含**：国际化（i18n）相关工作（已确认）
- **不包含**：邮件/短信通知通道（仅 L3 可选）
- **不包含**：跨服务团队管理（仅限本系统内）

#### T1.3 后端: POST /api/teams/{id}/transfer

**新增端点**:
```python
class TeamTransfer(BaseModel):
    new_owner_id: int
    confirm: bool = False

@router.post("/{team_id}/transfer")
async def transfer_ownership(...): ...
```

**业务规则**:
- 仅 owner 可发起
- 接收方必须是本团队 member 且 role ≠ viewer
- 接收方 role 强制为 manager

- confirm=False 时返回 400（防误操作）
- 写入 `team_ownership_transferred` 审计

**验收**:
- [ ] 非 owner 403
- [ ] 选择 viewer → 400
- [ ] confirm=False → 400
- [ ] 转让后原 owner 不再是 owner
- [ ] 审计日志含 old_owner + new_owner
