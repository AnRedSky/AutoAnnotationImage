## 与外部论文目录的关系

| 维度 | 项目内（`thesis-image-annotation/`） | 外部论文目录（`毕业论文设计与实现/`） |
|---|---|---|
| 关注 | 系统实现 + 代码 | 论文撰写 + 模板 + 反馈 |
| 内容 | API 文档、ORM 实况、训练 pipeline、构建产物 | 论文草稿、目录、参考文献、模板 |
| 维护 | 跟随代码 | 跟随论文写作进度 |
| 共享 | 截图 / 性能数据 / 实验结果 | 引用本目录的实现素材 |

**引用约定**：
- 本项目 docs 的文档提到"论文第 X 章"时，特指外部论文目录 `毕业论文设计与实现/docs/draft/chX-*.md`
- 论文文档提到"实现细节"时，反向引用本项目 `thesis-image-annotation/docs/2-后端实现记录.md` 或 `3-前端实现记录.md`
