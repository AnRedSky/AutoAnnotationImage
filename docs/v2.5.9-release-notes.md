## 一、版本亮点

### 标注工作台 UX 精细化 (S13)

- 三种任务类型 (分类/检测/分割) **画布布局 + 缩放交互完全统一** (0.25x-8x, 滚轮 1.15 / 按钮 1.25)
- 目标检测从绘制/编辑双模式合并为**智能标注模式** (鼠标按下按优先级自动判定行为)
- 标签交互增强: **X 删除按钮 + 确认对话框 + 类别排序 + el-popover 类别下拉**
- 修复保存按钮 disabled (emit dirty-change 事件 + 父组件本地 ref 同步)

### 前端架构优化 (S14)

- Annotate.vue 从 **1059 行拆分至 597 行** (4 层组件 + 3 个 composable)
- 前端项目**整体架构优化**: 8 个 view 模块化 + 15 个组件私有化 (19 文件 git mv 迁移)
- 标注工作台新增**左侧操作指导栏** (3 栏布局, 按任务类型展示工作流程/快捷键/注意事项)
- **画布布局优化**: canvasLayout.ts 工具 + 统一 info-panel + ResizeObserver 自适应填充容器

## 二、按 Tag 划分的变更

### S13 — 标注工作台 UX 精细化

#### v2.5.1 — 统一布局 + 修复保存按钮 disabled

- SegmentationAnnotator 极简化重构 (移除内部工具栏, 与检测端风格对齐)
- 三种任务右侧面板统一为 el-card + 8 sections 编号前缀
- 保存按钮 disabled 修复: emit('dirty-change') + 父组件本地 ref 同步
- SegmentationAnnotator 新增 cancel() 方法 (从快照恢复 mask)

#### v2.5.2 — 任务类型定义 + 缩放交互统一

- taskType.ts 增加 definition / output / scenario 三字段
- 新建 ClassificationAnnotator.vue (分类任务缩放支持)
- 三种任务统一缩放标准: MIN_ZOOM=0.25 / MAX_ZOOM=8.0 / 滚轮 1.15 / 按钮 1.25
- SegmentationAnnotator 从 Ctrl+滚轮改为直接滚轮, 系数 1.2→1.25
- Annotate.vue 顶部任务类型徽章改为 el-popover 包裹

#### v2.5.2-fix — 修复分类缩放集成 + 移除分割冗余缩放

- `<img>` 标签替换为 `<ClassificationAnnotator>` (v2.5.2 创建但未真正引用)
- 移除分割面板 Section 4 冗余缩放控制 (与子组件顶部控制条重复)
- 移除隐藏的 Section 5 (v-if="false" 占位, v2.5.0 至今未启用)

#### v2.5.3 — 检测面板重构

- 工具模式 + 历史操作 4 按钮合并为一行 (size="small" + gap:4px)
- 新增"目标类型" el-select 下拉, 始终显示
- Section 从 8 个减为 6 个

#### v2.5.3-patch — 画完 bbox 自动切编辑模式

- onMouseUp 创建新 bbox 后追加 setMode('edit')
- 符合 Figma / X-AnyLabeling / CVAT 习惯

#### v2.5.4 — 智能标注模式 + 修复 el-tag 删除

- 绘制/编辑双模式合并为单一智能标注模式
- 鼠标按下 3 优先级: handle → resize / bbox → select+move / 空白 → 画新
- 移除 setMode / mode ref / D-E 快捷键
- 修复 el-tag 关闭按钮静默失效 (defineExpose 暴露 removeBBoxAt)

#### v2.5.5 — 标签交互增强

- DOM overlay X 删除按钮 (18x18 红色圆形, 跟随选中 bbox 右上角)
- confirmAndRemove (ElMessageBox.confirm 确认对话框)
- sortedCategories (按 id 升序)
- 选中高亮动画 (scrollIntoView + 1.5s pulse)

#### v2.5.5-fix / v2.5.5-fix-2 — 修复 TDZ 错误

- watch getter 引用 TDZ 中的 const 声明, setup 阶段触发 TDZ
- 修复: 把 watch 块移到 ref 定义后

#### v2.5.6 — 面板 Section 重组 + popover 集成

- Section 2「选中 bbox」完全移除
- Section 5「当前 bbox」集成 el-popover 类别下拉 (trigger=manual)
- Section 从 6 个减为 5 个
- Annotate.vue 1537 → 1525 行

### S14 — 前端架构优化

#### v2.5.7 — Annotate.vue 子组件 + composable 拆分

- Annotate.vue 1059 → 597 行 (-43.6%)
- 新增 2 页面私有子组件: AnnotationToolbar.vue (254 行) / AnnotationCanvas.vue (52 行)
- 新增 3 业务通用组件: ClassificationPanel.vue (133) / DetectionPanel.vue (321) / SegmentationPanel.vue (208)
- 新增 3 composable: useDetectionAnnotate.ts (196) / useSegmentationAnnotate.ts (124) / useAutoAnnotate.ts (198)
- 附带 TS strict Bug 修复: findCategory(c.label)→c.name, accuracy ?? 0

#### v2.5.8 — 前端项目整体架构优化

- 8 个 view 文件从平铺 → 模块化文件夹 + index.vue 入口
- 15 个组件从 src/components/ → 各 view 私有 components/ 子目录
- 全部 git mv, similarity 97-100%, 历史追溯无断裂
- import 路径从 @/components/xxx 改为 ./components/xxx
- 路由更新: 8 处 '@/views/Xxx.vue' → '@/views/Xxx/index.vue'
- UploadQueue 跨页面共享用相对路径 '../Datasets/components/UploadQueue.vue'

#### v2.5.9 — 标注工作台操作指导栏

- 新增 AnnotationGuideSidebar.vue (362 行)
- 3 栏布局: 左侧 17% 指导栏 + 中间 50% 画布 + 右侧 33% 面板
- 3 种任务类型各有 4 段式文案 (工作流程/快捷键/任务专属/注意事项)
- 当前任务高亮, 其它任务折叠为摘要

#### commit 7ed575a — 画布布局优化

- 新增 canvasLayout.ts (261 行): CANVAS_W/CANVAS_H/WRAP_W/WRAP_H/SAFE_ZONE 常量 + clampToWrap/isOverlapCanvas/getImageDrawRect 函数
- 三个 annotator 组件统一右上角 info-panel 两行紧凑布局
- AnnotationCanvas.vue 改为 flex 布局, 画布完全填充容器
- useCanvasSize composable + ResizeObserver 监听容器尺寸变化
- 窗口/侧栏缩放时自动触发重绘
