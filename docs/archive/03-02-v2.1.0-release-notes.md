# v2.1.0 Release Notes

> v2.1.0 — 画布组件完整化 (S7 后续)
> 发布日期: 2026-07-19
> 基于: v2.0.0 (任务类型拓展: 检测 + 分割)

## 🎯 核心特性

补全 v2.0.0 留下的 **检测 / 分割画布组件** 缺口, 让 Annotate.vue 在 3 种任务类型下都有完整的标注 UI:

| 任务类型 | 画布组件 | 标注方式 | 持久化 |
|---|---|---|---|
| 图像分类 (classification) | (沿用原 img + AI Top-5) | 点选候选 + 类别下拉 | `POST /api/annotations/submit` |
| 目标检测 (detection) | **DetectionAnnotator (新)** | canvas 拖拽画 bbox + 类别下拉 | `clearBBoxes` + `saveBBox` |
| 图像分割 (segmentation) | **SegmentationAnnotator (新)** | canvas 画刷 / 橡皮 + 调色板 | `uploadMask` (PNG) |

## 📦 新增组件

### 1. `DetectionAnnotator.vue` (~430 行)
- canvas 画布 + HiDPI 兼容
- 鼠标拖拽绘制新 bbox (mousedown → mousemove → mouseup)
- 实时渲染已有 bbox (按 category_id 颜色分组, 8 色调色板)
- bbox 选中 / 删除 / 类别改写
- 双模式: `draw` (绘制) / `edit` (编辑)
- dirty 检测 + 保存 / 取消按钮
- 归一化坐标 (0-1) 存储, 与后端 BBoxAnnotation 一致

### 2. `SegmentationAnnotator.vue` (~480 行)
- 双 canvas 叠层: 底层原图 + 上层 mask 半透明
- 三模式: `brush` (画刷) / `erase` (橡皮) / `pan` (查看)
- 笔刷大小可调 (2-40px slider)
- 调色板: 按 category_id 8 色, 选中态高亮
- 已有 mask 自动加载并作为初始 mask
- 实时统计已标像素数 / 总像素
- 保存时 `canvas.toBlob` 转 PNG File, 走 `uploadMask`

### 3. `Annotate.vue` task_type 分派
- 按 `image.task_type` 条件渲染不同 annotator
- classification 任务: 沿用原 img + 右侧 AI Top-5 候选卡
- detection 任务: DetectionAnnotator + 右侧 AI 卡隐藏
- segmentation 任务: SegmentationAnnotator + 右侧 AI 卡隐藏
- 切换图片时自动加载已有 bbox / mask

## 🔧 API 客户端调整

- `segmentationApi.getMask(imageId, download=true)`: 增加 `responseType: 'blob'`, 直接拿 PNG 二进制
- 其他 detection/segmentation 端点保持不变 (S3/S5 已实现)
