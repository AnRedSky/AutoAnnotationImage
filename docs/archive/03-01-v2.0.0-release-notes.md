> 发布日期: 2026-07-19
> 代码冻结: v2.0.0

## 🎯 核心特性

在 v1.0.0 (图像分类) 基础上, v2.0.0 拓展支持 **3 种任务类型**:

| 任务类型 | 后端模型 | 前端支持 | 导出格式 | 状态 |
|---|---|---|---|---|
| 图像分类 (classification) | timm ImageNet (6 个 backbone) | ✅ 完整 | COCO / YOLO / CSV | ✅ v1.0.0 稳定 |
| 目标检测 (detection) | YOLOv8 (n/s/m/l/x) | ✅ 完整 | YOLO-det / COCO-det | ✅ v2.0.0 新增 |
| 图像分割 (segmentation) | DeepLabV3+ (resnet50/101) | ✅ 完整 | VOC-seg / COCO-seg | ✅ v2.0.0 新增 |

## 📦 新增能力

### 1. 数据模型扩展 (S1)
- `BBoxAnnotation` (目标检测边界框)
- `SegmentationMask` (图像分割掩码)
- `Image.task_type` (任务类型枚举: classification/detection/segmentation)
- `ModelVersion.task_type` + 任务专属指标 (mAP@0.5 / mIoU 等)

### 2. 后端 API (S2-S6)
- `/api/detection/annotations/*` — bbox CRUD
- `/api/detection/train` + `/api/detection/auto-annotate` — YOLOv8 训练 + 自动标注
- `/api/segmentation/masks/*` — mask CRUD
- `/api/segmentation/train` + `/api/segmentation/auto-annotate` — DeepLabV3+ 训练 + 自动标注
- `/api/export/{yolo-det,coco-det,voc-seg,coco-seg}` — 4 种任务专用导出端点
- 几何计算服务 (IoU / NMS)

### 3. 异步任务 (S3.2 / S5.2)
- Celery 训练任务 (YOLOv8 / DeepLabV3+)
- Celery 自动标注任务
- Redis 进度缓存 + SSE 实时推送

### 4. 前端 UI (S7)
- `utils/taskType.ts` — 任务类型元信息 + 训练参数提示 + 指标字段映射
- `Annotate.vue` — 数据集选择旁加任务类型徽章
- `Training.vue` — 按 task_type 动态切换 base_model (yolov8n / deeplabv3_resnet50)
- `Models.vue` — 任务类型筛选下拉 + 表格任务类型列
- API 客户端: `detectionApi` / `segmentationApi` / `exportApiV2`

## 🐛 已知限制

1. **前端 DetectionAnnotator / SegmentationAnnotator 完整画布组件**: 当前仅完成 API 客户端 + task_type 适配, 完整 canvas 拖拽画 bbox / mask 留作 S8 之后扩展 (论文 demo 用 AI 预标注 + 后端 bbox API 已可演示)
2. **COCO-seg segmentation**: 当前用 polygon (4 顶点外接矩形) 等价表达, 完整连通域 RLE 需要 pycocotools
3. **训练可视化**: Models.vue 详情页有混淆矩阵 (classification), 检测 / 分割的可视化待扩展
