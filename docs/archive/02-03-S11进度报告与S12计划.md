**风险**: CPU 慢 + 权重下载 (6MB yolov8n)

### S12.2 — 论文 6 张插图 (P0, 论文第 4 章)

**目标**: 采集 6 张 UI 截图 + 1 张性能表

**实现**:
- 启动 dev server (后端 + 前端 + Celery)
- browser_mcp 访问 6 个页面 + 截图
- 写入 `docs/draft/figures/fig-X-Y.png` (1080p)
- 每张配 100-200 字说明

**风险**: 依赖 dev server 状态 (用户机是否在跑)

### S12.3 — 分割任务布局统一 (P1)

**目标**: 跟 S10 检测一样, 8 sections 全部在右侧

**实现**:
- SegmentationAnnotator.vue 加 `defineExpose` (mode / selectedClass / canUndo / redo / clear / setMode / save)
- Annotate.vue 分割任务 v-else-if (line 1218) 填 8 sections:
  1. 工具模式 (刷子/橡皮/平移)
  2. 当前颜色
  3. 选中 mask 属性
  4. 历史操作
  5. 复制建议
  6. 图片导航
  7. 当前 mask 列表
  8. 提交

**风险**: SegmentationAnnotator 只 373 行, 改动量小于检测 779→682, 风险中

### S12.4 — 训练可视化 mAP/mIoU 切换 (P1)

**目标**: 训练任务详情页按 task_type 显示不同曲线

**实现**:
- Training.vue 详情弹窗按 task_type 分支:
  - classification → loss + accuracy (已实现, v2.2.3)
  - detection → box_loss / cls_loss / dfl_loss / mAP50 / mAP50-95 / precision / recall (v2.2.3 已部分)
  - segmentation → loss + mIoU + pixel_acc + dice
- TrainingJobOut schema 加 segmentation_metrics (JSON)

**风险**: 需后端 schema 调整 + 数据存储路径
