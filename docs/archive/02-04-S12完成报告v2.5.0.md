## 二、S12 详细改动

### S12.3a SegmentationAnnotator 增强 (commit 8f6a7ef)

**文件**: `frontend/src/components/annotation/SegmentationAnnotator.vue` (373→545 行, +172)

新增能力：
1. **画布缩放** — Ctrl+滚轮 / `+` / `-` / `100%` 控制条 (0.25x-8x)
2. **画布坐标浮标** — 左下角 (x, y) 像素坐标 + 当前类别色块；右下角 (画布尺寸 + 缩放百分比)；左上角 (模式徽章)
3. **全局快捷键** — B=画刷 / E=橡皮 / V=查看 / Space=临时平移
4. **defineExpose 暴露** — `mode / dirty / brushCategoryId / brushSize / zoom / mousePos / setMode / setCategory / setBrushSize / zoomIn / zoomOut / resetZoom / save / resetInitial`
5. **dirty-change 事件** — 通知父组件右侧面板
6. **新工具栏布局** — 在 v2.1 工具栏基础上加缩放控制

### S12.3b Annotate 分割任务 8 sections 面板 (commit 115612a)

**文件**: `frontend/src/views/Annotate.vue` (1322→1492 行, +180)

替换原 v2.3.0 占位 `<el-empty>`，新增 8 sections：
1. **工具模式** — el-radio-button 三选一
2. **当前画刷类别** — el-select (从 dataset categories 选)
3. **笔刷大小** — el-slider 2-40px
4. **画布缩放** — `+` / `100%` / `-` 按钮组
5. **跨图复制建议** — 占位 (v2.6.0 接入)
6. **图片导航** — 上一张 (P) / 下一张 (N)
7. **mask 状态** — 画布尺寸 + 已标像素 + 鼠标坐标
8. **提交** — 保存 mask (有 dirty 才启用) + 清空

辅助改动：
- `segAnnotRef` / `segMode` / `segMaskStatsLabel` 状态
- `onSegModeChange / onSegCategoryChange / onSegSave / onSegClear` 4 个 handler
- `autoSaveBeforeSwitch` 扩展支持分割任务 (用 watch dirty=false 等待)
- `<SegmentationAnnotator>` 加 `ref="segAnnotRef"` + 复用已有 `loadSegmentationMask`

### S12.4 训练可视化分割任务曲线 (commit ad86e45)

**文件**: `frontend/src/views/Training.vue` (+47 行)

新增 1 套曲线分支：
- **Init chart**：`isSegmentation` 走 `setOption` 创建「分割训练曲线 (Loss / mIoU / Pixel Acc / Dice)」
  - 5 条 series: train_loss, val_loss, mIoU, pixel_acc, dice
  - 双 Y 轴: 左轴 Loss, 右轴 0-1 范围指标
- **Watch history**：`isSegmentation` 走 `EpochData.miou / pixel_acc / dice` 字段更新
- **EpochData type 扩展**：加 3 个可选字段 `miou? / pixel_acc? / dice?`

配套后端：
- `backend/app/schemas/training.py` TrainingJobOut 加 `task_type` 字段 (commit 984add0)
  - 详情页前端用 `task_type` 判断渲染哪套曲线
  - 模型已有 task_type 列 (`training_jobs.task_type`, 索引)
