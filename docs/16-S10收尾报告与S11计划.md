## 二、复盘: S10 暴露的工作流问题

**S10 阶段 4 个"函数/import 漏定义"patch** (patch / patch2 / patch4 / patch5-重复函数) **全是 Edit 工具的同类问题**:

1. Edit 的 old_string 描述与实际文件差异 → noop 静默成功
2. 没有 git diff 验证环节
3. 没有"修改后跑测试"前置门槛

**改进方案 (S11 引入)**:

| # | 改进 | 实施方式 |
|---|---|---|
| 1 | 提交前必跑测试 | `pytest tests/test_xxx.py -q` 后再 commit |
| 2 | 提交前必跑 build | `npm run build` 通过后再 commit |
| 3 | 提交前必看 diff | `git diff --staged` 人工通读 |
| 4 | 单次 commit ≤ 3 文件 | 拆 commit, 减少失误面 |
| 5 | Edit 后立刻 grep 验证 | `grep -c "<func-name>"` 应 ≥ 1 |
