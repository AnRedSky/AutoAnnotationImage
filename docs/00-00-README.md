## 五、阅读建议

1. **准备阶段**：先阅读  6-02-项目说明文档.md 建立项目整体认知
2. **第 3 章写作**：从  1-01-系统功能设计文档.md 开始，了解系统设计
3. **第 4 章写作**：按  2-02 → 02-03 → 04-01 → 03-01 顺序阅读实现记录
4. **第 5 章写作**：以  4-03 → 04-04 → 04-05 为核心，配合  4-06 模块级数据
5. **过程证据**：如需引用开发过程，参考 rchive/02-xx 系列 Sprint 报告

参考 rchive/02-01 到 rchive/02-07，了解 v1.0.0 → v2.5.9 的演进过程。

## 六、与外部论文目录的关系

docs/ 是**项目内**文档（系统开发记录），与 毕业论文设计与实现/docs/（论文草稿目录）独立：

- **项目内 docs/**：系统开发过程、模块设计、测试结果、技术决策
- **毕业论文 docs/**：论文正文、参考文献、答辩材料、附录

论文写作时，从项目内 docs 引用素材到毕业论文 docs。
