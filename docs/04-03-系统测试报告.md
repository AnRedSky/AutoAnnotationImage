## 四、问题与改进

### 4.1 已修复

- ✅ 训练进度回调粒度（5 batch → 100 batch）
- ✅ 训练异常时半成品清理
- ✅ 模型激活并发安全（`with_for_update()` 行锁）
- ✅ 训练 API 契约补 `current_epoch` / `total_epochs` 字段

### 4.2 已知缺陷

- ⚠️ Celery worker 启动慢（首次加载 timm 模型约 30s），可通过预热缓解
- ⚠️ MySQL `LONGTEXT` 字段在存储大量 JSON 时查询慢（training_log），建议改用 `JSON` 类型

### 4.3 待改进

- 📝 pytest 覆盖率当前约 60%，目标 ≥ 80%
- 📝 缺少压力测试（locust / k6）
- 📝 前端缺少 E2E 测试（仅手动）
