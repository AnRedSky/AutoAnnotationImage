> **审查日期**: 2026-07-22

## 一、审查概览

### 1.1 文档 vs 实况偏差

| 维度 | 文档记录 (2-后端实现记录.md) | 实际代码 | 偏差 |
|---|---|---|---|
| API 路由数 | 42 | **~83** | 文档仅记录 v1.0.0 路由，v2.0.0 新增的 detection (15) / segmentation (8) / 训练管理扩展 (9) 等共 ~41 个端点未归档 |
| ORM 模型数 | 7 | **9** | BBoxAnnotation + SegmentationMask 未记录 |
| Schema 模块数 | 5 | **7** | detection.py + segmentation.py + enums.py 未记录 |
| Celery 任务模块 | 2 (tasks.py) | **3** (6 个任务) | detection_tasks.py + segmentation_tasks.py 未记录 |
| Service 层 | 2 | **3** | bbox_service.py 未记录 |

### 1.2 审查结论

后端 v2.0.0 ~ v2.5.x 迭代中新增了大量检测/分割相关代码，但后端实现记录文档停留在 v1.0.0 (W3 收官)。代码层面存在 **4 个 P0 级缺陷** (会导致运行时错误) 和 **6 个 P1 级问题** (安全/架构风险)。测试覆盖方面，ML 核心模块和 Worker 任务执行逻辑存在显著缺口。

## 二、问题清单

### 2.1 P0 — 运行时缺陷 (需立即修复)

| 编号 | 模块 | 问题描述 | 影响 | 建议修复 | 负责人 |
|---|---|---|---|---|---|
| BE-001 | `workers/detection_tasks.py` | `auto_annotate_pretrained_task` 写 BBoxAnnotation 时引用了不存在的 `model_name` 字段 (BBoxAnnotation ORM 无此列) | 预训练模型自动标注会抛 IntegrityError，功能不可用 | 移除 `model_name` 赋值或改为写入 `AnnotationLog` 的 meta 字段 | |
| BE-002 | `workers/detection_tasks.py` | `auto_annotate_pretrained_task` 写 `AnnotationLog.action="auto_annotate_pretrained"`，但 `AnnotationLog.action` 枚举仅含 `ai_predict/confirm/correct/reject` | SQLAlchemy Enum 校验失败，日志写入报错 | 改为 `action="ai_predict"` 并在 `message` 或新增字段中标注来源 | |
| BE-003 | `workers/celery_app.py` | `include` 列表为 `["app.workers.tasks", "app.workers.detection_tasks"]`，**缺少 `segmentation_tasks`** | 分割训练/自动标注任务可能未被 worker 注册 (当前靠 API 层 import 触发注册，若 worker 先于 API 启动则任务丢失) | 在 `include` 中添加 `"app.workers.segmentation_tasks"` | |
| BE-004 | `api/training.py` | `start_training` 是同步 `def` 而非 `async def`，在 FastAPI 中占用 threadpool；内部调用 `_run_async` 在某些上下文会触发 "event loop already running" | 训练启动可能间歇性失败 | 改为 `async def` 并直接 await 数据库操作 | |

## 五、Celery 任务完整清单 (3 模块 / 6 个任务)

### 5.1 `workers/tasks.py` (classification)

| 任务 | 说明 |
|---|---|
| `train_model_task` | 分类训练: 加载数据 → train/val split → timm 训练 → 保存最佳模型 → 写 TrainingJob SUCCESS + ModelVersion；支持 `pretrained_model_path` 增量训练；`TrainingPaused` 异常写 PAUSED |
| `auto_annotate_task` | 分类预标注: 加载模型 → batch_predict → filter_predictions_to_categories → 写 ai_prediction + status=ai_labeled |

### 5.2 `workers/detection_tasks.py` (v2.0.0)

| 任务 | 说明 |
|---|---|
| `train_detection_task` | YOLOv8 训练: export_yolo_dataset → ultralytics train → 写 ModelVersion (map_50/map_50_95) |
| `auto_annotate_detection_task` | 用已训练 ModelVersion 批量推理 → 写 BBoxAnnotation(source=ai) |
| `auto_annotate_pretrained_task` | 用预训练 yolov8n/s/m/l/x 自动标注 → 写 BBoxAnnotation(source="pretrained") |

### 5.3 `workers/segmentation_tasks.py` (v2.0.0)

| 任务 | 说明 |
|---|---|
| `train_segmentation_task` | DeepLabV3+ 训练: collect_segmentation_pairs → train_segmentation → 写 ModelVersion (miou/pixel_accuracy) |
| `auto_annotate_segmentation_task` | 加载 ModelVersion → predict_to_mask_image → 写 SegmentationMask(source=ai) |

### 5.4 关键设计模式

- **训练任务预创建**: API 层预生成 UUID → INSERT PENDING TrainingJob → apply_async(task_id=UUID) → worker UPDATE 而非重复 INSERT (消除竞态)
- **增量训练**: `mode=restart` 自动查找 is_active ModelVersion → 传 `pretrained_model_path` → 加载旧 state_dict 作为起点
- **FAILURE 序列化**: 所有 task 异常路径必须 `self.update_state(state="FAILURE", meta={..., "exc_type": ...})`，否则 Celery 抛 ValueError
- **SSE 进度推送**: DB 优先策略 + 签名去重 + 终端态主动 `event: end` + 15s keepalive
