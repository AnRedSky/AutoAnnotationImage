## 二、分析

### 2.1 训练效率

从训练时长看，**EfficientNet-B0** 最快（856 秒），适合 CPU 环境。
ResNet50 居中（1104 秒），ConvNeXt-Tiny 最慢（1245 秒），但精度最高。

### 2.2 精度表现

**ConvNeXt-Tiny** 的 F1 分数最高（0.8290），但参数量最大（28.6M）。
EfficientNet-B0 精度仅低 0.009，但参数量只有 1/5，速度快 31%。

### 2.3 参数效率

EfficientNet-B0 参数量最少（5.3M），但 F1 仍能达到 0.8201，
在精度和推理速度之间取得**最佳平衡**。
