# 团队管理用户手册 (v3.3.1)

> 本手册面向最终用户, 介绍如何创建/管理团队、邀请成员、共享数据集、查看团队动态等操作.
> 适用版本: v3.3.1+

---

## 一、团队管理概述

### 1.1 团队是什么

团队是若干用户组成的协作单元, 用于:
- 共享数据集 (所有成员可见)
- 协作标注
- 统一权限管理
- 审计追踪

### 1.2 角色权限

| 角色 | 你能做什么 |
|---|---|
| **创建者 (owner)** | 全部权限, 包括转让所有权 |
| **可管理 (manager)** | 邀请/移除成员, 编辑团队, 共享数据集 |
| **可编辑 (editor)** | 对共享数据集进行标注 |
| **仅阅读 (viewer)** | 只读访问, 不能标注 |

---

## 二、创建你的第一个团队

### 步骤

1. 进入「团队管理」页面 (左侧菜单)
2. 点击右上角「创建团队」按钮
3. 填写表单:
   - **团队名称** (必填, 后续可修改)
   - **团队标识 (slug)** (可选, 系统会自动从名称生成)
   - **描述** (可选)
   - **最大成员数** (默认 20, 范围 2-100)
4. 点击「确认」

### 自动发生的事

- 你自动成为该团队的创建者 (owner)
- 系统生成默认 slug, 冲突时自动追加数字 (`my-team` → `my-team-2`)
- 写入审计日志: `team_created`

---

## 三、邀请成员

### 步骤

1. 进入团队详情页
2. 点击「邀请成员」按钮 (仅 manager / owner 可见)
3. 在弹窗中:
   - 输入用户名关键字 (支持搜索)
   - 从下拉列表选择用户
   - 选择角色 (manager / editor / viewer)
4. 点击「确认邀请」

### 常见问题

**Q: 团队已满怎么办?**
A: 联系创建者提升「最大成员数」(创建者可改为 100 以内任何值).

**Q: 邀请错了角色?**
A: 在成员列表中, 点击该成员右侧的「编辑角色」, 可修改为其他角色.

**Q: 用户已经在团队里了?**
A: 系统会提示「用户已在团队中」, 不会重复添加.

## 四、转让所有权

> 适用场景: 创建者希望卸任, 或希望其他人接管.

### 步骤

1. 进入团队详情页
2. 点击「转让所有权」按钮 (仅 owner 可见)
3. 在弹窗中:
   - 选择新 owner (必须已是团队成员, 不能是 viewer)
   - 输入团队名称确认 (防误操作)
4. 点击「确认转让」

### 自动发生的事

- 新 owner 自动获得 manager 角色
- 原 owner (你) 仍保留 manager 角色 (避免权限真空)
- 写入审计日志: `team_ownership_transferred` (含 old_owner / new_owner)

### 注意事项

- 转让后, 你的角色从 owner 变成 manager
- 只有 manager 才能转让 (viewer / editor 看不到此按钮)
- 接收方不能是 viewer 角色, 系统会提示错误

## 五、主动退队

> 适用场景: 不再参与该团队的工作.

### 步骤

1. 进入团队详情页
2. 点击「退出团队」按钮
3. 在确认弹窗中点击「确认」

### 限制

- **创建者 (owner) 不能直接退队**, 必须先转让所有权
- 退出后, 你将:
  - 失去团队成员身份
  - 无法访问团队共享的数据集
  - 但已标注的记录会保留 (作为历史)

### 自动发生的事

- 从成员表删除你的记录
- 写入审计日志: `team_left`

---

## 六、共享数据集给团队

> 适用场景: 你有数据集, 希望团队成员可以一起标注.

### 步骤

1. 进入「数据集详情」页 (任一你创建的数据集)
2. 找到「共享」按钮 (通常在数据集头部)
3. 在弹窗中:
   - 选择目标团队
   - **输入数据集名称** 二次确认 (防误操作)
   - 查看「影响范围」(该团队 X 名成员将可访问)
4. 点击「确认共享」

### 自动发生的事

- 数据集 `team_id` 字段被设置
- 团队所有成员自动获得访问权限
- 写入审计日志: `dataset_shared_to_team`

### 取消共享

- 同样在「数据集详情」页, 点击「取消共享」
- 团队成员将立即失去访问权限
- 写入审计日志: `dataset_unshared_from_team`

---

## 七、查看团队动态

> 适用场景: 了解团队最近发生了什么.

### 步骤

1. 进入团队详情页
2. 切换到「团队动态」 Tab
3. 可选:
   - 按动态类型过滤 (创建/邀请/转让/...)
   - 点击「详情」按钮查看 JSON 详情

### 显示内容

按时间倒序展示:
- 谁在什么时间做了什么
- 事件类型 (用颜色标签区分)
- 操作人 + 时间 + 资源

### 自动发生的事

- 数据来源: audit_log 表 (团队相关)
- 默认最多显示 50 条
- 团队成员可见活跃团队的活动
- admin 可查看已归档团队的活动

---

## 八、查看团队统计

> 适用场景: 了解团队的工作量、成员贡献、趋势.

### 步骤

1. 进入团队详情页
2. 切换到「数据统计」 Tab
3. 选择时间范围 (7/14/30 天)
4. 查看:
   - 团队规模 (成员/数据集)
   - 标注进度饼图
   - 7/14/30 天活动折线
   - Top 5 贡献柱状图
   - AI 节省时间

## 九、归档与恢复

### 归档 (软删除)

- 进入团队列表, 在团队卡片右侧点击「删除」
- 确认后, 团队进入「已归档」状态
- 自动发生:
  - 数据集 `team_id` 被清空 (避免悬挂引用)
  - 团队成员保留, 但无法访问
  - 写入审计日志: `team_deleted`

### 恢复 (admin only)

- 仅系统管理员可恢复
- admin 切换 `include_archived=true` 后可看到已归档团队
- 点击「恢复」, 团队恢复正常状态
- 写入审计日志: `team_restored`

## 十、常见问题

### Q1: 我加入了一个团队, 找不到入口?
A: 团队列表只显示「我创建或已加入」的团队. 如果是别人邀请你, 邀请完成后会自动出现在列表中.

### Q2: 我是 manager, 但看不到「编辑团队」按钮?
A: 编辑权限需要 manager 角色. 联系 owner 提升你的角色.

### Q3: 我把最后一名 manager 移除了, 团队怎么办?
A: 系统会阻止此操作 (最后一名 manager 保护). 必须先提升其他成员为 manager.

### Q4: 我创建了团队, 后来不想管了, 怎么删?
A: 请先「转让所有权」给其他成员, 然后让对方删除. 或者: 创建者自己直接删除, 但这会归档整个团队.

### Q5: 团队活动 Feed 没有数据?
A: 检查:
1. 是否在正确的团队详情页
2. 该团队是否有最近的写操作 (创建/邀请/编辑等)
3. 时间范围是否正确 (默认显示最近 50 条)

### Q6: 我看到「命中率 0%」缓存监控?
A: 表示系统刚启动, 还没有缓存访问. 正常使用后会逐渐累积.

## 十一、最佳实践

1. **命名规范**: 团队名称应该能反映职责, 如「视觉算法组」「数据标注小组」
2. **权限最小化**: 默认邀请 editor, 必要时再提升 manager
3. **定期审计**: 通过「团队动态」/「审计日志」定期检查异常操作
4. **及时归档**: 不再使用的团队及时归档, 避免数据混乱
5. **共享确认**: 共享数据集前, 在弹窗中输入数据集名二次确认, 防止误操作
