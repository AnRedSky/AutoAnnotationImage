## 五、Celery 任务（2 个）

### 5.1 `train_model_task`

- **入参**：`dataset_id, base_model, model_name, user_id, epochs, batch_size, learning_rate`
- **流程**：
  1. 创建 `TrainingJob` 记录（state=PENDING）
  2. 加载数据集 + 划分 train/val 8:2
  3. 加载 timm 预训练模型
  4. 训练循环（每 epoch 回调 `epoch_cb`）
  5. 评估（混淆矩阵 + 4 指标）
  6. 创建 `ModelVersion` 记录
  7. 关联 `TrainingJob.model_version_id`
  8. state=SUCCESS 或 FAILURE
- **持久化**：每 epoch 写入 `train:history:{task_id}` Redis key

### 5.2 `auto_annotate_task`（W2 新增）

- **入参**：`dataset_id, model_name, confidence_threshold, user_id`
- **流程**：
  1. 加载 timm 模型
  2. 批量推理（每 10 张更新一次进度）
  3. 按阈值分流：
     - top1_conf ≥ threshold → status=ai_labeled
     - top1_conf < threshold → 保持 pending
  4. 写回数据库
- **进度**：通过 `self.update_state(state='PROGRESS', meta={progress, msg})`
