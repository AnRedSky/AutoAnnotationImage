### 复现命令

```bash
# 1) 启动后端
python scripts/start_local.py backend

# 2) 一次性生成测试图（已有则跳过）
python scripts/fixtures.py

# 3) 跑稳定性测试（3 轮）
python scripts/run_e2e.py --repeat 3

# 4) 如需回退到临时 PNG 模式
python scripts/run_e2e.py --no-fixtures
```

### 改进点

- **可复现**：fixture 文件名稳定，多次运行覆盖即可，无需外部数据源
- **更真实**：10 张图尺寸/格式/颜色各异，比 1 张 32×32 PNG 更接近真实场景
- **更快**：复用磁盘文件，省去每次编码 PNG 的开销
- **更易调试**：失败时可直接拿 `backend/tests/fixtures/images/fixture_*.png` 重现
- **稳定性证据**：3 轮 26/26 全通过，证明系统无状态依赖、无残留数据干扰

## 复现

```bash
# 1) 启动后端 + Celery worker + 前端
cd backend
uvicorn app.main:app --reload &
celery -A app.workers.celery_app worker --loglevel=info &

cd ../frontend
npm run dev &

# 2) 准备数据 (200 张图, 含类别标签)
cd ../backend
python scripts/prepare_demo_data.py
# 把 demo/data/cifar10_subset/train/ 下的图上传到系统

# 3) 跑 E2E (会覆盖本节件)
python tests/e2e_run.py

# 4) 采集截图
python tests/collect_screenshots.py
```
