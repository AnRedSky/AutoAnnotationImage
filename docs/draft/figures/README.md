## 采集流程

### 自动化（E2E 截图）

```bash
cd backend
# 1) 启动前后端
# 后端: uvicorn app.main:app --reload
# 前端: cd frontend && npm run dev

# 2) 一键采集 6 张图
python tests/collect_screenshots.py
# 输出: docs/e2e/screenshots/*.png

# 3) 把 e2e/screenshots/ 复制到本目录, 按 fig-X-Y-描述.png 重命名
```

### 手工（架构图、模块图）

1. 打开 https://app.diagrams.net/
2. 按系统架构绘制 → 导出为 PNG → 重命名为 `fig-3-1-系统架构图.png`
3. 按功能模块绘制 → 导出为 PNG → 重命名为 `fig-3-2-功能模块图.png`

### Excel CSV 截图

1. 在前端导出 CSV：`GET /api/export/csv/{dataset_id}` → 保存到本地
2. 用 Excel 打开 → 截图 → 重命名为 `fig-4-6-导出CSV样例.png`

## 图片要求

| 维度 | 要求 |
|---|---|
| 分辨率 | ≥ 1080p（1920×1080 推荐） |
| 格式 | PNG（无损） |
| 大小 | 单张 < 2 MB |
| 命名 | 严格按 `fig-X-Y-描述.png` |
| 内容 | 不含个人信息、清晰可读 |
