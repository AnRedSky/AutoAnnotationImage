## 三、8 个页面清单

> **v2.5.8 更新**: 所有 view 从 `Xxx.vue` 平铺 → `Xxx/index.vue` 模块化入口。DatasetDetail 为 v2.0.0 新增页面 (W3 后)。

### 3.1 `Login/index.vue`

- **功能**：登录 / 注册 Tabs
- **API**：`authApi.login()`（OAuth2 form-data）+ `authApi.me()` + `authApi.register()`
- **状态**：`useUserStore.setAuth(token, user)`
- **路由**：登录成功 → `router.push('/')`
- **UI**：登录页背景渐变（#667eea → #764ba2），卡片居中 420px

### 3.2 `Layout/index.vue`

- **功能**：主布局（侧栏 + 顶栏 + 内容区）
- **侧栏菜单**（5 项）：
  - 仪表盘（Odometer）
  - 数据集（Folder）
  - 标注工作台（EditPen）
  - 模型版本（Grid）
  - 训练任务（Promotion）
- **顶栏**：折叠按钮 + 当前页标题 + 用户下拉（头像 + 角色 Tag + 退出登录）
- **登出**：`authApi.logout()` + 清空 store + 跳 `/login`
- **折叠**：64px ↔ 220px 切换

### 3.3 `Dashboard/index.vue`

- **统计卡**（4 个 + 3 个 AI 子卡）：
  - 数据集 / 图片总数 / 已标注 / 模型版本
  - AI 节省时间 / 平均耗时 / AI 命中
- **图表**（4 个 ECharts）：
  - 图片状态分布（饼图）
  - AI 置信度分布（柱状图）
  - 近 14 日标注量（折线 + 区域）
  - 标注员效率（双 Y 轴：标注数 / 平均秒数）
- **数据源**：`statsApi.{overview, dataset, confidence, timeline, annotatorEfficiency}`
- **联动**：选择数据集 → 重载 4 个图表

### 3.4 `Datasets/index.vue`

- **CRUD**：列表 / 创建（含批量创建类别）/ 删除
- **上传**：`<el-upload drag multiple>` → `imageApi.upload()`
- **类别管理**：弹窗 + 添加/列表
- **AI 预标注**：一键调用 `autoAnnotateApi.run()`
- **导出**：下拉菜单（COCO / YOLO / CSV），fetch + Blob 下载
- **API**：`datasetApi`, `imageApi`, `autoAnnotateApi`, `exportApi`

### 3.5 `Annotate/index.vue`（**论文核心创新点 1**）

> **v2.5.7 拆分**: 1059 → 597 行, 拆出 2 页面私有子组件 + 3 业务通用组件 + 3 composable
> **v2.5.9**: 612 行 (+15 行指导栏集成), 3 栏布局 (4+12+8=24)
> **v2.5.1-v2.5.6**: 三种任务类型 (分类/检测/分割) 统一画布 + 缩放交互 + 智能标注模式

- **3 栏布局**：左侧操作指导栏 (AnnotationGuideSidebar) + 中间画布 (AnnotationCanvas) + 右侧操作面板
- **顶部控制** (AnnotationToolbar)：数据集 / 任务类型徽章 / 预训练模型 / 置信度阈值 / 启动预标注
- **统计卡**：已标注 / AI 命中 / 节省时间 / 平均耗时
- **画布区** (AnnotationCanvas)：按 task_type 分派 ClassificationAnnotator / DetectionAnnotator / SegmentationAnnotator
- **右侧面板**：按 task_type 分派 ClassificationPanel / DetectionPanel / SegmentationPanel
- **目标检测**：智能标注模式 (无模式切换) + X 删除按钮 + el-popover 类别下拉 + 撤销栈
- **图像分割**：双 canvas 叠层 + 画刷/橡皮 + 8 色调色板 + mask 上传
- **缩放交互** (三种任务统一)：MIN_ZOOM=0.25 / MAX_ZOOM=8.0 / 滚轮 1.15 / 按钮 1.25
- **耗时统计**：`Date.now() - startTs` 实时记录 → 写入 `AnnotationLog`

### 3.6 `Training/index.vue`（**论文核心创新点 3**）

> **v2.5.0 S12.4**: 按 task_type 显示 3 套训练曲线 (classification / detection / segmentation)
> **v2.5.8**: 私有组件归位 (TrainingParamsForm / StateBadge / BaseModelSelect)

- **启动表单**：数据集 / 基础模型 / 版本名 / 轮次 / 批大小 / 学习率
- **进度卡片**：状态 / 进度 / 已记录 epoch
- **ECharts 训练曲线**：4 条线（train_loss / val_loss / train_acc / val_acc）
- **日志区**：滚动文本框（黑底绿字）
- **轮询**：每 3 秒调用 `/api/training/progress/{id}` + `/api/training/history/{id}`
- **历史任务表**：ID / 数据集 / 基础模型 / 版本 / 轮次 / 状态 / 进度 / 耗时 / 开始时间

### 3.7 `Models/index.vue`

- **表格列**：ID / 名称 / 基础模型 / 状态 / 准确率 / 精确率 / 召回率 / F1 / 训练集 / 类别数 / 创建时间 / 操作
- **多选对比**：勾选 2 个 → 点击"对比所选" → 弹窗显示：
  - 卡片 A / 卡片 B（基础模型 + 准确率）
  - 指标差异（4 个 Δ，绿色 = 提升 / 红色 = 下降）
  - 混淆矩阵（JSON 展示）
- **激活按钮**：调用 `modelApi.activate(id)` → 重新加载列表

## 四、API 客户端

### 4.1 `api/http.ts`

```typescript
// Axios 实例
baseURL: '/api'  // Vite 代理到 http://127.0.0.1:8000
timeout: 30000

// 拦截器
请求：自动注入 Authorization: Bearer {token}
响应：
  - 401 → 清 token + 跳 /login
  - 403 → 提示"无权限"
  - 500+ → 提示"服务器内部错误"
```

### 4.2 `api/index.ts` 11 个模块

| 模块 | 端点数 | 主要方法 |
|---|---|---|

| datasetApi | 6 | list / create / get / remove / categories×2 |
| imageApi | 4 | upload / autoLabel / list / fileUrl |
| annotationApi | 2 | save / stats |
| autoAnnotateApi | 3 | run / status / models |
| trainingApi | 5 | start / progress / history / jobs×2 |
| modelApi | 4 | list / detail / activate / compare |
| exportApi | 3 | coco / yolo / csv（直接返回 URL） |
| statsApi | 5 | overview / dataset / confidence / timeline / annotatorEfficiency |
