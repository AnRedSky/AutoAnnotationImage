## 二、Phase 1: Repository 层抽取 (2 人天)

### 2.1 目标

### 2.2 实施步骤

#### 步骤 1.1: 创建 Repository 基类 (0.5 天)

**新增**: `repositories/base.py`

```python
"""
通用 Repository 基类: 封装 ORM ↔ Domain Entity 转换
"""
from typing import Generic, TypeVar, Optional, List
from sqlalchemy.ext.asyncio import AsyncSession

T = TypeVar("T")  # Entity 类型


class BaseRepository(Generic[T]):
    """通用 CRUD 封装"""

    def __init__(self, db: AsyncSession):
        self._db = db

    async def commit(self) -> None:
        await self._db.commit()

    async def rollback(self) -> None:
        await self._db.rollback()

    async def refresh(self, entity: T) -> T:
        await self._db.refresh(entity)
        return entity
```

```python
from abc import ABC, abstractmethod
from typing import Optional, List
from datetime import datetime
from .entities import TrainingJobEntity, TrainingMetrics, TrainingState


class TrainingJobRepository(ABC):
    @abstractmethod
    async def create(self, job: TrainingJobEntity) -> int: ...
    @abstractmethod
    async def get_by_id(self, job_id: int) -> Optional[TrainingJobEntity]: ...
    @abstractmethod
    async def get_by_celery_task_id(self, celery_task_id: str) -> Optional[TrainingJobEntity]: ...
    @abstractmethod
    async def list_by_user(self, user_id: int, *, limit: int = 50, offset: int = 0) -> List[TrainingJobEntity]: ...
    @abstractmethod
    async def update_state(self, job_id: int, state: TrainingState, progress: Optional[float] = None, message: Optional[str] = None) -> None: ...
    @abstractmethod
    async def append_history(self, job_id: int, metrics: TrainingMetrics) -> None: ...
    @abstractmethod
    async def update_started_at(self, job_id: int, started_at: datetime) -> None: ...
    @abstractmethod
    async def update_finished_at(self, job_id: int, finished_at: datetime, state: TrainingState) -> None: ...
    @abstractmethod
    async def delete(self, job_id: int) -> None: ...
```

- 移除 `import app.database` / `from app.models import ...`
- 移除 `_run_async` 事件循环管理
- 函数签名改为接收 `train_data: list` (图像路径 + 标签) + 回调
- 返回值改为 `Dict[str, Any]` 包含 `best_model_path` + `metrics` + `class_names`

#### 步骤 9.2: 重构 `ml/detection/yolo_train.py` (0.75 天)

同上, 输出 YOLO best.pt + metrics

#### 步骤 9.3: 重构 `ml/segmentation/seg_train.py` (0.75 天)

同上, 输出 DeepLab best.pth + metrics

#### 步骤 9.4: Service 接管持久化 (含 Phase 3)

`TrainingService.execute_training()` 负责:
1. 调 `dataset_repo.get_by_id()` 加载数据集
2. 调 `ml.train.run_classification_training()` (纯计算)
3. 调 `model_version_repo.create()` 持久化 ModelVersion
