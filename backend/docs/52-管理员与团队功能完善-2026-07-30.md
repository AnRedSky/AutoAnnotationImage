## 一、用户管理 (仅管理员可见)

### 功能清单

| 功能 | 说明 |
|---|---|
| 用户列表 | 分页 (15/页) + 搜索 (用户名/邮箱/角色) |
| 改角色 | 4 种角色: super_admin / admin / annotator / viewer + 描述 |
| 启停账号 | 激活/停用, 防误操作自己 |
| 权限控制 | super_admin 仅 super_admin 可管, 不能操作自己 |
| 自我标识 | "我" tag 标记当前登录用户 |

### 路由守卫

```
meta: { requireAdmin: true }
→ router.beforeEach: if (!store.user?.role?.includes('admin')) → 403
```

侧边栏菜单仅在 `isAdmin` 时显示管理员菜单组 (用户管理 / 角色权限 / 审计日志)。

## 二、团队管理 (全部用户可见)

### 功能清单

| 功能 | 说明 |
|---|---|
| 团队列表 | 显示我加入的所有团队 + 我的角色 |
| 创建团队 | 任何已登录用户可创建, 创建者自动成为队长 (leader) |
| 进入团队 | 点击"进入管理" → 成员管理详情视图 |
| 邀请成员 | 队长/admin 可邀请, 选用户 + 角色 (leader/annotator/viewer) |
| 改成员角色 | 队长可修改成员角色 (先移除再邀请, 后端无 update 端点) |
| 移除成员 | 队长可移除非队长成员 |
| 删除团队 | 仅队长/admin, 删除后共享数据集变为个人 |
| 配额检查 | 成员数 >= max_members 时禁止邀请 |
| 可用用户过滤 | 邀请下拉只显示不在团队中的用户 |

### 路由

```
/teams → Teams.vue (全部用户可见, 无 requireAdmin)
侧边栏主菜单: "团队管理"
```

### 团队角色

| 角色 | 权限 |
|---|---|
| leader (队长) | 管理成员 + 编辑数据集 + 删除团队 |
| annotator | 可标注共享数据集 |
| viewer | 只读 |
