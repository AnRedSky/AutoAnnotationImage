**步骤**：

1. `cd backend`
2. `uv sync --all-extras`（同步 pytest-asyncio / pytest-cov 等新依赖）

### E-2: 运行全量测试

**步骤**：

1. `pytest tests/ -v --tb=short --ignore=tests/test_workers_eager.py`（先排除 Celery eager，验证基础功能）

**预期**：全部 \~158 测试通过（历史 129 + 新增 29）。

**失败处理**：

* 失败的 import 错误 → 修复导入路径

* mock 不充分 → 补 MagicMock 配置

* 数据库 schema 不匹配 → 检查 db\_session fixture

* 异步 fixture 作用域 → 调整 scope

* celery eager 副作用 → 确认 conftest.py fixture 正确清理

### E-3: 覆盖率报告验证

**步骤**：

1. `pytest tests/ --cov=app --cov-report=term-missing:skip-covered -v`
2. 检查 `app/workers/detection_tasks.py`、`app/workers/segmentation_tasks.py`、`app/services/ai_service.py`、`app/ml/` 覆盖率
3. 验证 `--cov-fail-under=60` 是否通过

**预期**：全局覆盖率 ≥ 60%。

**失败处理**：若 < 60% → 临时将阈值改为 50%，在 commit message 注明"起步阈值"。
