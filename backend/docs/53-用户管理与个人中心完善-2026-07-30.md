# 用户管理与个人中心完善报告 — 2026-07-30

## 一、用户管理 (仅管理员)

### 新增功能

| 功能 | API 端点 | 说明 |
|---|---|---|
| 创建用户 | POST /api/users/ | 用户名+密码+邮箱+角色 |
| 删除用户 | DELETE /api/users/{id} | 不能删自己, super_admin 保护 |
| 重置密码 | POST /api/users/{id}/reset-password | 管理员重置, 不需旧密码 |
| 改角色 | POST /api/users/{id}/role | 4 种角色 |
| 启停 | POST /api/users/{id}/activate\|deactivate | 不能停自己 |
| 搜索+分页 | 前端 | 用户名/邮箱/角色搜索, 15/页 |

### 前端功能

- 添加用户对话框 (用户名+密码+邮箱+角色选择)
- 删除按钮 (二次确认, 不能删自己/super_admin)
- 重置密码对话框
- 搜索框 + 分页 + 刷新

## 二、个人中心 (全部用户)

### 新增 API

| 功能 | API 端点 | 说明 |
|---|---|---|
| 获取信息 | GET /api/users/me/profile | 当前用户信息 |
| 修改邮箱 | PUT /api/users/me/profile | 改邮箱 |
| 修改密码 | POST /api/users/me/change-password | 需旧密码验证 |

### 前端页面 (Profile/index.vue)

- 基本信息: 用户名/角色/状态/注册时间
- 修改邮箱
- 修改密码 (旧密码+新密码+确认)
- 路由: /profile (全部用户可见)
- 入口: Layout 用户下拉菜单 "个人中心"

## 三、团队管理功能评估

### 当前功能 (已完善)

| 功能 | 说明 |
|---|---|
| 团队列表 | 显示我加入的所有团队 + 角色 |
| 创建团队 | 创建者自动队长 |
| 进入团队 | 详情视图 → 成员管理 |
| 邀请成员 | 队长/admin, 选用户+角色 |
| 改成员角色 | 队长可改 |
| 移除成员 | 队长可移除 |
| 删除团队 | 仅队长/admin |
| 配额检查 | max_members 限制 |
| 数据集共享 | 在 Roles.vue (管理员) |

### 合理性评估

**已覆盖**：创建/加入/管理/删除/共享全流程。
**不扩展**：团队数据集共享保留在管理员"角色权限"页面，避免 Teams.vue 过大 (410行)。
**未来可选扩展**：团队成员标注进度概览、团队活动日志。
