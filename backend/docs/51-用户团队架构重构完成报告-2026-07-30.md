## 架构

```
管理员 (admin/super_admin)
  ├── 管理全部用户 (CRUD + 启停 + 改角色)
  ├── 查看全部数据集/模型/训练任务/审计日志
  └── 全局视角, 不属于任何团队

用户 (annotator/viewer)
  ├── 独立标注: 自己创建的数据集
  ├── 创建团队: 创建 Team → 邀请其他用户加入
  ├── 团队共享: 把数据集共享给团队
  └── 团队角色: leader (管理+编辑) / annotator (标注) / viewer (只读)
```

### 数据模型

| 表 | 说明 |
|---|---|
| Team | id, name, slug, owner_id, max_members, created_at |
| TeamMember | team_id, user_id, role (leader/annotator/viewer), joined_at |
| Dataset | 加 team_id (nullable: null=个人, 非null=团队共享) |
| User | role (super_admin/admin/annotator/viewer), 无 tenant_id |

### 权限检查

统一 helper `assert_can_access_dataset(db, current_user, dataset, require_write=False)`:
1. admin/super_admin → 全通
2. owner → 全通
3. team_member (dataset.team_id 非空) → 通过 (viewer 写操作被拒)

15 处 API 端点调用此 helper, 替代旧的 `is_admin() and owner_id != current_user.id`。
