# 团队角色权限重构报告 — 2026-07-30

## 一、角色改名

| 旧角色 | 新角色 | 权限 |
|---|---|---|
| leader | **manager** (可管理) | 管理成员 + 配置数据集权限 + 编辑标注 |
| annotator | **editor** (可编辑) | 可对共享数据集进行标注 |
| viewer | **viewer** (仅阅读) | 只读 |

## 二、冗余功能删除

| 删除项 | 原因 |
|---|---|
| `Roles.vue` (角色权限页) | 与 Teams.vue 详情视图重叠 (成员管理+数据集共享) |
| `/admin/roles` 路由 | 冗余 |
| 菜单"角色权限" | 冗余 |

**效果**: 管理员菜单从 3 项→2 项 (用户管理 + 审计日志)。团队管理在主菜单 (全部用户可见)。

## 三、后端新增

| 端点 | 说明 |
|---|---|
| `PUT /api/teams/{id}/members/{uid}` | 修改成员角色 (不用先删再加) |
| `TeamMember.can_manage()` | manager 角色判断 |
| `TeamMember.can_edit()` | manager + editor 判断 |
| `WRITE_ROLES` | ("manager", "editor") — 写权限角色集 |
| `_assert_can_manage()` helper | 统一管理权限检查 |

## 四、DB 迁移

```sql
-- team_member.role ENUM 从 leader/annotator/viewer 改为 manager/editor/viewer
ALTER TABLE team_member MODIFY COLUMN role ENUM('leader','annotator','manager','editor','viewer');
UPDATE team_member SET role='manager' WHERE role='leader';
UPDATE team_member SET role='editor' WHERE role='annotator';
ALTER TABLE team_member MODIFY COLUMN role ENUM('manager','editor','viewer');
```
