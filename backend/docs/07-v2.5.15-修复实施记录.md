## 关键设计决策

| 决策点 | 选择 | 理由 |
|---|---|---|
| P0-1 model_name 字段 | 写入 `AnnotationLog.payload` 而非新建 ORM 字段 | 避免 migration 复杂度 + 字段语义不清 |
| P0-2 枚举扩展 | 加 `auto_annotate_pretrained` / `auto_annotate_finetuned` 2 个值 | 区分两种 auto-annotate 场景, 审计更清晰 |
| P0-4 async 重构 | `def` → `async def`, 删除 `_run_async` 嵌套 | 与 `start_existing_training_job` L932-938 模式一致 |
| P1-1/2 安全 | `model_validator` 生产 fail-fast, 开发 WARN | 不破坏开发体验, 生产严格 |
| P1-3 CORS | 生产必须显式 origin, 开发 * 自动降级 credentials=False | 浏览器规范 + 兼容性平衡 |
| P1-5 模型池 | `ModelPool` LRU + `threading.Lock` + `max_size=2` | 预训练+fine-tuned 双 model 是主流场景 |
| P1-6 批处理 | `torch.stack` 拼 batch, 默认 `batch_size=8` | CPU 模式 sweet spot (再大内存爆) |
| git commit | 按 Phase 拆 11 个独立 commit | 便于 review + bisect 回滚 |

### C-2: `ModelPool` LRU + 锁 (4.5 h)

**修改文件**: `backend/app/services/ai_service.py` 头部 + `AIService.__init__`

```python
# 顶部 import 区增加
import threading
from collections import OrderedDict
from typing import Tuple, Any, Callable

# AIService 类之前
class ModelPool:
    """LRU 模型池, 解决 ai_service 单例互踩问题

    - 池内按 (model_key, variant) 缓存已加载 model
    - get_or_load 串行化 (threading.Lock) 保证并发安全
    - max_size 默认 2: 预训练 + fine-tuned 主流场景
    - 不影响 ModelVersion.activate (DB 层与池完全解耦)
    """
    def __init__(self, max_size: int = 2):
        self._max_size = max_size
        self._cache: "OrderedDict[Tuple[str, str], Any]" = OrderedDict()
        self._lock = threading.Lock()
        self.hits = 0
        self.misses = 0

    def get_or_load(
        self, model_key: str, variant: str,
        loader_fn: Callable[[], Any],
    ) -> Any:
        cache_key = (model_key, variant)
        with self._lock:
            if cache_key in self._cache:
                self.hits += 1
                self._cache.move_to_end(cache_key)
                return self._cache[cache_key]
            self.misses += 1
            while len(self._cache) >= self._max_size:
                self._cache.popitem(last=False)
            model = loader_fn()
            self._cache[cache_key] = model
            return model

    def clear(self) -> None:
        with self._lock:
            self._cache.clear()
            self.hits = 0
            self.misses = 0

    def stats(self) -> dict:
        with self._lock:
            total = self.hits + self.misses
            return {
                "size": len(self._cache),
                "max_size": self._max_size,
                "hits": self.hits,
                "misses": self.misses,
                "hit_rate": (self.hits / total) if total else 0.0,
            }
```

**改造 `load_pretrained` / `load_local`**:
- 用 `self._pool.get_or_load(model_name, "pretrained", _loader)` 替换直接赋值给 `self.current_model`
- 保留 `self.current_model` 作为最近一次的引用 (向后兼容, 主要给 `_predict_sync` 用)
- `_predict_sync` 优先用 `self.current_model`, 缺失时报错 "No model loaded"

### C-3: `batch_predict` 真批处理 (3 h)

**修改文件**: `backend/app/services/ai_service.py` L250-253 + 新增 `_batch_predict_sync`

```python
async def batch_predict(
    self, image_paths: List[str], top_k: int = 5, batch_size: int = 8,
) -> List[Dict]:
    """真 batch forward (拼 batch tensor, 一次 forward 跑 batch_size 张)

    性能: 32 张图从 22s 降到 ~6s (CPU)
    """
    if not image_paths:
        return []
    loop = asyncio.get_event_loop()
    return await loop.run_in_executor(
        self._executor, self._batch_predict_sync,
        list(image_paths), top_k, batch_size,
    )

def _batch_predict_sync(
    self, image_paths: List[str], top_k: int, batch_size: int,
) -> List[Dict]:
    """同步真批处理: torch.stack 拼 batch, 一次 forward"""
    import torch
    from PIL import Image
    if self.current_model is None:
        raise RuntimeError("No model loaded. Call load_pretrained/load_local first.")
    
    # 1) 全部 image 预处理
    transform = self._build_transform(self.current_model)
    tensors: list = []
    paths_ok: list = []  # 记录哪些路径成功 read
    failed_idx: set = set()
    for i, p in enumerate(image_paths):
        try:
            img = Image.open(p).convert("RGB")
            t = transform(img)
            tensors.append(t)
            paths_ok.append(p)
        except Exception:
            failed_idx.add(i)
    
    if not tensors:
        return [None] * len(image_paths)  # type: ignore[return-value]
    
    # 2) 分批 forward
    results_by_path: dict = {}
    num_classes = None
    for start in range(0, len(tensors), batch_size):
        batch = torch.stack(tensors[start:start + batch_size]).to(self.device)
        with torch.no_grad():
            logits = self.current_model(batch)
            probs = torch.softmax(logits, dim=1)
            if num_classes is None:
                num_classes = probs.shape[-1]
            actual_k = max(1, min(top_k, num_classes))
            top_probs, top_indices = probs.topk(actual_k, dim=1)
        
        for j, (probs_row, idxs_row) in enumerate(zip(top_probs, top_indices)):
            path = paths_ok[start + j]
            results_by_path[path] = (probs_row.cpu(), idxs_row.cpu())
    
    # 3) 对齐到原 image_paths 顺序, 失败的填 None
    out: list = []
    for i, p in enumerate(image_paths):
        if i in failed_idx or p not in results_by_path:
            out.append(None)  # type: ignore[arg-type]
            continue
        probs_row, idxs_row = results_by_path[p]
        # 转 label 逻辑 (复用 _predict_sync 内的查找表逻辑)
        imagenet_classes = self.current_model.default_cfg.get("classes") or []
        if isinstance(imagenet_classes, list) and not self._imagenet_label_lookup:
            self._imagenet_label_lookup = {i: n for i, n in enumerate(imagenet_classes)}
        results = []
        for prob, idx in zip(probs_row, idxs_row):
            idx_int = idx.item()
            if self._custom_label_map is not None and idx_int in self._custom_label_map:
                label = self._custom_label_map[idx_int]
            else:
                label = (
                    self._imagenet_label_lookup.get(idx_int)
                    or self._demo_labels.get(idx_int)
                    or f"class_{idx_int}"
                )
            results.append({"label": label, "confidence": round(prob.item(), 4)})
        out.append({
            "top1": results[0]["label"],
            "top1_conf": results[0]["confidence"],
            "top5": results,
        })
    return out  # type: ignore[return-value]
```

**重要**: 返回值改为 `List[Optional[Dict]]`, 与 `filter_predictions_to_categories` 输入输出对齐。需要修改调用方 (主要是 `app/api/image.py:auto_label` 的 `for img, pred in zip(images, predictions)`) 对 `pred is None` 显式处理 (其实它已经有 `if pred is None: continue` 类似的逻辑, 需检查)。**实施时先 grep 所有 batch_predict 调用方确认**。
