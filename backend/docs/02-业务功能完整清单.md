## 三、业务流程串联

### 3.1 分类任务全流程

```
1. 注册/登录 (auth)
2. 创建数据集 (datasets, task_type=classification, 含类目)
3. 上传图片 (images/upload, 批量)
4. AI 预标注 (auto-annotate/run, timm)
5. 人工修正 (annotations/save, 写 final_label_id)
6. 启动训练 (training/start, base_model=efficientnet_b0)
7. 监控进度 (training/progress/stream, SSE)
8. 训练完成 → ModelVersion 自动生成
9. 激活模型 (models/{id}/activate)
10. 再次 AI 预标注 (使用新模型)
11. 数据导出 (export/coco|yolo|csv)
```

### 3.2 目标检测任务全流程 (v2.0.0) ⭐

```
1. 创建数据集 (datasets, task_type=detection)
2. 上传图片 (images/upload)
3. 人工标注 BBox (detection/annotations/save, 归一化坐标)
   或预训练模型标注 (detection/auto-annotate-pretrained, yolov8n)
4. 启动 YOLO 训练 (detection/train, epochs/bs/lr/imgsz)
5. 监控进度 (detection/jobs/{id}/stream, SSE)
6. 训练完成 → ModelVersion (map_50/map_50_95)
7. 激活检测模型 (detection/models/{id}/activate)
8. 用已训练模型批量标注 (detection/auto-annotate)
9. 检测统计 (detection/stats, 散点图)
10. 导出 (export/yolo-det|coco-det)
```

## 五、关键功能深度解析

### 5.1 训练任务预创建 (消除竞态)

```python
# API 层
@router.post("/start")
def start_training(...):
    celery_task_id = uuid.uuid4().hex  # 预生成
    # 1. 预创建 PENDING 行
    db.execute(insert(TrainingJob).values(
        celery_task_id=celery_task_id, state="PENDING", ...
    ))
    db.commit()
    # 2. 强制 Celery 用此 ID 入队
    train_model_task.apply_async(task_id=celery_task_id, kwargs={...})

# Worker 层
@celery_app.task(bind=True)
def train_model_task(self, ...):
    task_id = self.request.id
    existing = db.execute(
        select(TrainingJob).where(TrainingJob.celery_task_id == task_id)
    )
    if existing:
        existing.state = "PROGRESS"  # UPDATE 而非 INSERT
```

**效果**: 前端提交后立即 GET 查得到, 不会出现"提交后短暂空白"。

### 5.2 SSE 实时进度推送

```python
# 服务端
async def event_stream(task_id):
    while True:
        # 1. DB 优先
        job = db.get(TrainingJob, task_id)
        if job.state in ('SUCCESS', 'FAILURE'):
            yield f"event: end\ndata: {json.dumps(...)}\n\n"
            break
        yield f"data: {json.dumps({progress: job.progress})}\n\n"
        # 2. 1s 心跳
        await asyncio.sleep(1.0)
        # 3. 15s keepalive
        if elapsed > 15:
            yield ": keepalive\n\n"
```

**效果**: 减少轮询压力, 实时性好, 兼容代理 (nginx buffering 关闭)。

### 5.3 数据集级 train/val 拆分 (固定种子)

# ml/detection/yolo_dataset.py
def split_train_val(image_ids, val_ratio=0.2, seed=42):
