# 架构分层重构方案 (v3.0.0)

---

## 一、设计原则

### 1.1 Clean Architecture 六边形分层

```
┌──────────────────────────────────────────────────────┐
│  Presentation (API/Workers/CLI)                       │  表达层: 协议适配
│  - FastAPI 路由, Celery 任务, CLI 命令                │  职责: 输入解析 + 响应构造
└──────────────────────────────────────────────────────┘
                       ↓
┌──────────────────────────────────────────────────────┐
│  Application (Services)                               │  应用层: 业务编排
│  - TrainingService, ImageService, ...                 │  职责: 业务规则 + 事务管理
└──────────────────────────────────────────────────────┘
                       ↓
┌──────────────────────────────────────────────────────┐
│  Domain (Entities / Value Objects / Events)          │  领域层: 业务核心
│  - TrainingJob, Image, Dataset, ...                   │  职责: 不变量 + 业务规则
└──────────────────────────────────────────────────────┘
                       ↓
┌──────────────────────────────────────────────────────┐
│  Infrastructure (Repositories / ML / External)        │  基础设施层: 技术细节
│  - SQLAlchemy Repo, timm, Redis, Celery Broker        │  职责: 持久化 + 外部服务
└──────────────────────────────────────────────────────┘
```

### 1.2 核心设计原则

| 原则 | 描述 | 体现 |
|---|---|---|
| **依赖倒置** | 高层不依赖低层, 都依赖抽象 | API 依赖 Service 接口, 不依赖 ORM |
| **单一职责** | 一个类/函数只做一件事 | TrainingService 只管训练编排, 不管 HTTP |
| **开闭原则** | 对扩展开放, 对修改关闭 | 新增任务类型只需加 Service 方法, 不改 Router |
| **接口隔离** | 客户端不依赖不需要的接口 | Service 方法按 use case 拆分, 避免胖接口 |
| **明确边界** | 层间通过数据对象 (DTO/Entity) 通信, 不共享 ORM 实例 | API 接收 Pydantic, 传出 Entity |
| **依赖注入** | 通过 `Depends()` 注入 Service, 不使用全局单例 | FastAPI `Depends(get_training_service)` |

### 1.3 不做的事 (Out of Scope)

- ❌ 不引入微服务 / 拆分进程 (单体 FastAPI 足够支撑当前规模)
- ❌ 不更换 ORM (SQLAlchemy 2.0 异步已满足需求)
- ❌ 不引入新的核心依赖 (避免 pydantic / sqlalchemy / celery 之外的重大变更)
- ❌ 不修改对外 HTTP 协议 (路径 / 请求 / 响应格式)
- ❌ 不重写 ML 训练算法 (timm / ultralytics / torchvision 保持)

### 2.2 层间通信协议

| 源层 | 目标层 | 传递对象 | 不允许 |
|---|---|---|---|
| API (HTTP) | Service | Pydantic Schema (请求) | 传 ORM 实例 |
| Service | Repository | Domain Entity / Value Object | 直接传 HTTP 请求 |
| Service | ML | 纯 Python dict / dataclass | 传 ORM Session |
| Worker | Service | Domain Entity / dict | 直接访问 ORM |
| Repository | ORM | SQLAlchemy Model | 直接返回 ORM 给 Service (应转 Entity) |

**Entity ↔ ORM 转换**:
- `models/training_job.py:TrainingJob` (ORM) → `domain/training/entities.py:TrainingJobEntity` (Domain)
- Repository 负责双向转换, Service 不感知 ORM

## 三、核心抽象设计

### 3.1 Domain Entity (领域实体)

#### 示例: `domain/training/entities.py`

```python
"""
领域实体: 训练任务 / 模型版本
不依赖 ORM, 仅承载业务规则与不变量
"""
from dataclasses import dataclass, field
from datetime import datetime
from enum import Enum
from typing import Optional, List, Dict, Any

class TrainingState(str, Enum):
    """训练状态枚举 (业务统一语义)"""
    PENDING = "PENDING"
    PROGRESS = "PROGRESS"
    SUCCESS = "SUCCESS"
    FAILURE = "FAILURE"
    REVOKED = "REVOKED"

@dataclass(frozen=True)
class TrainingMetrics:
    """训练指标值对象 (不可变)"""
    epoch: int
    train_loss: float
    val_loss: Optional[float] = None
    train_acc: Optional[float] = None
    val_acc: Optional[float] = None
    learning_rate: Optional[float] = None
    timestamp: datetime = field(default_factory=datetime.utcnow)

    def to_dict(self) -> Dict[str, Any]:
        return {
            "epoch": self.epoch,
            "train_loss": self.train_loss,
            "val_loss": self.val_loss,
            "train_acc": self.train_acc,
            "val_acc": self.val_acc,
            "lr": self.learning_rate,
            "timestamp": self.timestamp.isoformat(),
        }

@dataclass
class TrainingJobEntity:
    """训练任务领域实体 (可变)"""
    id: int
    celery_task_id: str
    user_id: int
    dataset_id: int
    task_type: str  # classification / detection / segmentation
    base_model: str
    model_name: str
    state: TrainingState
    progress: float = 0.0
    message: str = ""
    error: Optional[str] = None

    # 时间
    created_at: Optional[datetime] = None
    started_at: Optional[datetime] = None
    finished_at: Optional[datetime] = None
    duration_seconds: Optional[float] = None

    # 训练超参
    epochs: int = 20
    batch_size: int = 32
    learning_rate: float = 1e-4

    # 数据集统计
    data_total: Optional[int] = None
    data_train: Optional[int] = None
    data_val: Optional[int] = None
    num_classes: Optional[int] = None
    class_names: Optional[List[str]] = None

    # 训练历史 (用于曲线图)
    history: List[TrainingMetrics] = field(default_factory=list)

    # 增量训练
    pretrained_model_path: Optional[str] = None

    def is_terminal(self) -> bool:
        """业务规则: 终态判断"""
        return self.state in (TrainingState.SUCCESS, TrainingState.FAILURE, TrainingState.REVOKED)

    def transition_to(self, new_state: TrainingState, message: str = "") -> None:
        """业务规则: 状态机转移"""
        valid_transitions = {
            TrainingState.PENDING: {TrainingState.PROGRESS, TrainingState.REVOKED},
            TrainingState.PROGRESS: {TrainingState.SUCCESS, TrainingState.FAILURE, TrainingState.REVOKED},
            TrainingState.SUCCESS: set(),  # 终态
            TrainingState.FAILURE: set(),  # 终态
            TrainingState.REVOKED: set(),  # 终态
        }
        if new_state not in valid_transitions.get(self.state, set()):
            raise ValueError(
                f"非法状态转移: {self.state.value} -> {new_state.value}"
            )
        self.state = new_state
        if message:
            self.message = message

    def append_history(self, metrics: TrainingMetrics) -> None:
        """业务规则: 追加训练历史"""
        self.history.append(metrics)
        # 保留最近 1000 条, 避免内存爆炸
        if len(self.history) > 1000:
            self.history = self.history[-1000:]

    def duration(self) -> Optional[float]:
        """业务规则: 计算耗时"""
        if self.started_at and self.finished_at:
            return (self.finished_at - self.started_at).total_seconds()
        return None
```

```python
class TrainingJobRepository(ABC):
```

### 3.2 Repository 实现 (基础设施层)

```python
# repositories/training_job_repo.py
from typing import Optional, List
from sqlalchemy import select, update
from sqlalchemy.ext.asyncio import AsyncSession
from app.models.training_job import TrainingJob  # ORM
from app.domain.training.entities import TrainingJobEntity, TrainingMetrics, TrainingState
from app.domain.training.interfaces import TrainingJobRepository

class SQLAlchemyTrainingJobRepository(TrainingJobRepository):
    """基于 SQLAlchemy 的实现 (基础设施层)"""

    def __init__(self, db: AsyncSession):
        self._db = db

    # ===== ORM ↔ Entity 转换 =====

    def _to_entity(self, orm: TrainingJob) -> TrainingJobEntity:
        return TrainingJobEntity(
            id=orm.id,
            celery_task_id=orm.celery_task_id,
            user_id=orm.user_id,
            dataset_id=orm.dataset_id,
            task_type=orm.task_type,
            base_model=orm.base_model,
            model_name=orm.model_name,
            state=TrainingState(orm.state),
            progress=orm.progress or 0.0,
            message=orm.message or "",
            error=orm.error,
            created_at=orm.created_at,
            started_at=orm.started_at,
            finished_at=orm.finished_at,
            duration_seconds=orm.duration_seconds,
            epochs=orm.epochs,
            batch_size=orm.batch_size,
            learning_rate=orm.learning_rate,
            data_total=orm.data_total,
            data_train=orm.data_train,
            data_val=orm.data_val,
            num_classes=orm.num_classes,
            class_names=orm.class_names,
            history=[
                TrainingMetrics(
                    epoch=h.get("epoch"),
                    train_loss=h.get("train_loss", 0),
                    val_loss=h.get("val_loss"),
                    train_acc=h.get("train_acc"),
                    val_acc=h.get("val_acc"),
                    learning_rate=h.get("lr"),
                )
                for h in (orm.history or [])
            ],
            pretrained_model_path=orm.pretrained_model_path,
        )

    def _to_orm(self, entity: TrainingJobEntity) -> TrainingJob:
        return TrainingJob(
            id=entity.id,
            celery_task_id=entity.celery_task_id,
            user_id=entity.user_id,
            dataset_id=entity.dataset_id,
            task_type=entity.task_type,
            base_model=entity.base_model,
            model_name=entity.model_name,
            state=entity.state.value,
            progress=entity.progress,
            message=entity.message,
            error=entity.error,
            created_at=entity.created_at,
            started_at=entity.started_at,
            finished_at=entity.finished_at,
            duration_seconds=entity.duration_seconds,
            epochs=entity.epochs,
            batch_size=entity.batch_size,
            learning_rate=entity.learning_rate,
            data_total=entity.data_total,
            data_train=entity.data_train,
            data_val=entity.data_val,
            num_classes=entity.num_classes,
            class_names=entity.class_names,
            history=[m.to_dict() for m in entity.history],
            pretrained_model_path=entity.pretrained_model_path,
        )

    # ===== 接口实现 =====

    async def create(self, job: TrainingJobEntity) -> int:
        orm = self._to_orm(job)
        self._db.add(orm)
        await self._db.commit()
        await self._db.refresh(orm)
        return orm.id

    async def get_by_id(self, job_id: int) -> Optional[TrainingJobEntity]:
        orm = await self._db.get(TrainingJob, job_id)
        return self._to_entity(orm) if orm else None

    async def get_by_celery_task_id(self, celery_task_id: str) -> Optional[TrainingJobEntity]:
        result = await self._db.execute(
            select(TrainingJob).where(TrainingJob.celery_task_id == celery_task_id)
        )
        orm = result.scalar_one_or_none()
        return self._to_entity(orm) if orm else None

    async def update_state(
        self,
        job_id: int,
        state: TrainingState,
        progress: Optional[float] = None,
        message: Optional[str] = None,
    ) -> None:
        values = {"state": state.value}
        if progress is not None:
            values["progress"] = progress
        if message is not None:
            values["message"] = message
        await self._db.execute(
            update(TrainingJob).where(TrainingJob.id == job_id).values(**values)
        )
        await self._db.commit()

    async def append_history(self, job_id: int, metrics: TrainingMetrics) -> None:
        orm = await self._db.get(TrainingJob, job_id)
        if not orm:
            return
        history = orm.history or []
        history.append(metrics.to_dict())
        # 仅保留最近 1000 条
        if len(history) > 1000:
            history = history[-1000:]
        await self._db.execute(
            update(TrainingJob).where(TrainingJob.id == job_id).values(history=history)
        )
        await self._db.commit()
```

### 3.3 Service 层 (应用层, 业务编排)

```python
# services/training_service.py
from typing import Optional, List
import uuid
import asyncio
from datetime import datetime
from app.domain.training.entities import TrainingJobEntity, TrainingState, TrainingMetrics
from app.domain.training.interfaces import TrainingJobRepository, ModelVersionRepository
from app.core.exceptions import NotFoundError, ValidationError
from app.core.celery_utils import check_celery_available
from app.config import settings

class TrainingService:
    """训练业务编排 (应用层)"""

    def __init__(
        self,
        job_repo: TrainingJobRepository,
        model_repo: ModelVersionRepository,
        task_dispatcher: "TaskDispatcher",  # 抽象任务派发
    ):
        self._job_repo = job_repo
        self._model_repo = model_repo
        self._dispatcher = task_dispatcher

    # ===== Use Cases (业务用例) =====

    async def start_training(
        self,
        *,
        user_id: int,
        dataset_id: int,
        task_type: str,
        base_model: str,
        model_name: str,
        epochs: int,
        batch_size: int,
        learning_rate: float,
        pretrained_model_path: Optional[str] = None,
    ) -> TrainingJobEntity:
        """启动训练 (Use Case)"""
        # 1. 业务校验
        if epochs <= 0 or epochs > 1000:
            raise ValidationError("epochs 必须在 1-1000 之间")
        if not model_name or not model_name.strip():
            model_name = f"{base_model}_v1_{int(datetime.utcnow().timestamp())}"

        # 2. 预检 broker
        check_celery_available()

        # 3. 预创建任务
        celery_task_id = uuid.uuid4().hex
        entity = TrainingJobEntity(
            id=0,  # 新建
            celery_task_id=celery_task_id,
            user_id=user_id,
            dataset_id=dataset_id,
            task_type=task_type,
            base_model=base_model,
            model_name=model_name,
            state=TrainingState.PENDING,
            message="等待 worker 启动...",
            epochs=epochs,
            batch_size=batch_size,
            learning_rate=learning_rate,
            pretrained_model_path=pretrained_model_path,
        )
        job_id = await self._job_repo.create(entity)
        entity.id = job_id

        # 4. 派发到 Celery
        try:
            await self._dispatcher.dispatch(
                task_type=task_type,
                celery_task_id=celery_task_id,
                kwargs={
                    "dataset_id": dataset_id,
                    "user_id": user_id,
                    "base_model": base_model,
                    "model_name": model_name,
                    "epochs": epochs,
                    "batch_size": batch_size,
                    "learning_rate": learning_rate,
                    "pretrained_model_path": pretrained_model_path,
                },
            )
        except Exception as e:
            # 派发失败, 回滚
            await self._job_repo.delete(job_id)
            raise

        return entity

    async def get_progress(self, celery_task_id: str) -> dict:
        """查询训练进度 (Use Case)"""
```

```python
# ml/train.py (重构后, 不依赖 DB)
from typing import Callable, Optional, Dict, Any
from pathlib import Path

def run_training(
    *,
    train_data: list,  # 纯数据 (图像路径 + 标签)
    val_data: list,
    base_model: str,
    epochs: int,
    batch_size: int,
    learning_rate: float,
    output_dir: Path,
    pretrained_model_path: Optional[str] = None,
    progress_callback: Optional[Callable[[float, str, dict], None]] = None,
    epoch_callback: Optional[Callable[[dict], None]] = None,
) -> Dict[str, Any]:
    """分类训练 (纯计算)

    Args:
        train_data: 训练样本列表 [(image_path, label), ...]
        val_data: 验证样本列表
        output_dir: 模型保存目录
        progress_callback: 进度回调 fn(progress: float, msg: str, extra: dict)
        epoch_callback: 每 epoch 回调 fn({"epoch": int, "train_loss": ..., "val_loss": ..., ...})

    Returns:
        {
            "best_model_path": str,
            "best_accuracy": float,
            "metrics": {...},
            "class_names": [...],
            "confusion_matrix": [[...]],  # list 而非 ndarray (防 JSON 序列化失败)
        }
    """
    # 1. 加载模型
    if pretrained_model_path:
        model = load_finetune_model(pretrained_model_path, num_classes=len(set(l for _, l in train_data)))
    else:
        model = timm.create_model(base_model, pretrained=True, num_classes=len(set(l for _, l in train_data)))

    # 2. 训练循环
    for epoch in range(epochs):
        # ... 训练 + 验证
        if progress_callback:
            progress_callback(epoch / epochs, f"Epoch {epoch+1}/{epochs}", {})
        if epoch_callback:
            epoch_callback({
                "epoch": epoch + 1,
                "train_loss": train_loss,
                "val_loss": val_loss,
                "train_acc": train_acc,
                "val_acc": val_acc,
                "lr": optimizer.param_groups[0]["lr"],
            })

    # 3. 保存最佳模型
    best_path = output_dir / "best.pth"
    torch.save(model.state_dict(), best_path)

    # 4. 返回结果 (必须 JSON 可序列化)
    return {
        "best_model_path": str(best_path),
        "best_accuracy": float(best_accuracy),  # 显式 float 避免 numpy.float64
        "metrics": {k: float(v) for k, v in metrics.items()},
        "class_names": list(class_names),
        "confusion_matrix": cm.tolist(),  # ndarray → list
    }
```

```python
# services/training_service.py (续)
from app.ml.train import run_training as run_classification_training
from app.ml.detection.yolo_train import run_training as run_detection_training
from app.ml.segmentation.seg_train import run_training as run_segmentation_training

class TrainingService:
    # ... (前面略)

    async def execute_training(
        self,
        *,
        celery_task_id: str,
        dataset_id: int,
        user_id: int,
        base_model: str,
        model_name: str,
        epochs: int,
        batch_size: int,
        learning_rate: float,
        pretrained_model_path: Optional[str] = None,
    ) -> Dict[str, Any]:
        """执行训练 (Service 编排: 加载数据 + 调 ML + 持久化)"""
        # 1. 加载数据 (通过 Repository)
        dataset = await self._dataset_repo.get_by_id(dataset_id)
        train_data, val_data, class_names = await self._load_dataset(dataset, celery_task_id)

        # 2. 状态: PROGRESS

        # 3. 定义回调 (委托给 state_service)
        def progress_cb(progress, msg, extra):
            return run_async_in_worker(
                self._state_service.on_progress(celery_task_id, progress, msg, extra)
            )

        def epoch_cb(metrics):
            return run_async_in_worker(
                self._state_service.on_epoch(celery_task_id, metrics)
            )

        # 4. 调 ML 训练
        try:
            if task_type == "detection":
                result = run_detection_training(...)
            elif task_type == "segmentation":
                result = run_segmentation_training(...)
            else:
                result = run_classification_training(
                    train_data=train_data,
                    val_data=val_data,
                    base_model=base_model,
                    epochs=epochs,
                    batch_size=batch_size,
                    learning_rate=learning_rate,
                    output_dir=Path(settings.MODEL_DIR) / f"user_{user_id}" / "finetune" / model_name,
                    pretrained_model_path=pretrained_model_path,
                    progress_callback=progress_cb,
                    epoch_callback=epoch_cb,
                )
        except Exception as e:
            await self._state_service.on_failure(celery_task_id, str(e))
            raise

        # 5. 持久化 ModelVersion
        model_version_id = await self._model_repo.create(
            user_id=user_id,
            dataset_id=dataset_id,
            model_name=model_name,
            base_model=base_model,
            file_path=result["best_model_path"],
            num_classes=len(class_names),
            metrics=result["metrics"],
        )

        # 6. 状态: SUCCESS
        await self._state_service.on_success(celery_task_id, model_version_id)

        return {
            "status": "success",
            "model_version_id": model_version_id,
            "best_accuracy": result["best_accuracy"],
        }
```

## 四、状态机统一 (job_state_service)

### 4.1 设计

```python
# services/job_state_service.py
"""
训练状态机服务: 统一管理 TrainingJob + Celery meta + Redis 缓存

v2.5.x 的状态分散 (4 处真相源) 在此收敛:
- 唯一入口: state_service.on_xxx(celery_task_id, ...)
- 自动同步 DB (TrainingJob) + Celery meta + Redis (训练历史)
- 业务规则: 非法状态转移自动拒绝
"""
from datetime import datetime
from typing import Optional, Dict, Any
import json
from app.domain.training.entities import TrainingState, TrainingMetrics
from app.domain.training.interfaces import TrainingJobRepository
from app.core.redis_client import redis_client
from celery import current_task

class JobStateService:
    def __init__(self, job_repo: TrainingJobRepository):
        self._job_repo = job_repo

    # ===== 状态转移 =====

    async def on_start(
        self,
        celery_task_id: str,
        *,
        total_epochs: int,
    ) -> None:
        """Worker 接手任务"""
        job = await self._job_repo.get_by_celery_task_id(celery_task_id)
        if not job:
            return
        try:
            job.transition_to(TrainingState.PROGRESS, message="开始训练")
        except ValueError:
            pass  # 已经是 PROGRESS / SUCCESS, 跳过
        job.started_at = datetime.utcnow()
        await self._job_repo.update_started_at(job.id, job.started_at)
        await self._job_repo.update_state(
            job.id, TrainingState.PROGRESS, progress=0.0, message="开始训练"
        )
        # Celery meta
        if current_task:
            current_task.update_state(
                state="PROGRESS",
                meta={"progress": 0.0, "msg": "开始训练", "total_epochs": total_epochs}
            )

    async def on_progress(
        self,
        celery_task_id: str,
        progress: float,
        message: str,
        extra: Optional[Dict[str, Any]] = None,
    ) -> None:
        """进度更新 (每个 batch)"""
        # 1. Celery meta
        if current_task:
            current_task.update_state(
                state="PROGRESS",
                meta={"progress": progress, "msg": message, **(extra or {})}
            )
        # 2. DB (每 5% 写一次, 避免 DB 抖动)
        job = await self._job_repo.get_by_celery_task_id(celery_task_id)
        if not job:
            return
        if int(progress * 100) - int(job.progress * 100) >= 5 or progress >= 1.0:
            await self._job_repo.update_state(
                job.id, TrainingState.PROGRESS, progress=progress, message=message
            )

    async def on_epoch(
        self,
        celery_task_id: str,
        metrics: TrainingMetrics,
    ) -> None:
        """Epoch 完成"""
        # 1. Redis (训练历史曲线)
        key = f"train:history:{celery_task_id}"
        history_raw = redis_client.get(key)
        history = json.loads(history_raw) if history_raw else []
        history.append(metrics.to_dict())
        # 仅保留最近 1000 条
        if len(history) > 1000:
            history = history[-1000:]
        redis_client.setex(key, 86400, json.dumps(history))
        # 2. DB
        job = await self._job_repo.get_by_celery_task_id(celery_task_id)
        if job:
            await self._job_repo.append_history(job.id, metrics)

    async def on_success(
        self,
        celery_task_id: str,
        model_version_id: int,
    ) -> None:
        """训练成功"""
        job = await self._job_repo.get_by_celery_task_id(celery_task_id)
        if not job:
            return
        finished_at = datetime.utcnow()
        duration = (finished_at - job.started_at).total_seconds() if job.started_at else None
        job.finished_at = finished_at
        job.duration_seconds = duration
        try:
            job.transition_to(TrainingState.SUCCESS, message="训练完成")
        except ValueError:
            pass
        await self._job_repo.update_finished_at(job.id, finished_at, TrainingState.SUCCESS)
        await self._job_repo.update_state(
            job.id, TrainingState.SUCCESS, progress=1.0, message="训练完成"
        )

    async def on_failure(
        self,
        celery_task_id: str,
        error: str,
    ) -> None:
        """训练失败"""
        job = await self._job_repo.get_by_celery_task_id(celery_task_id)
        if not job:
            return
        finished_at = datetime.utcnow()
        try:
            job.transition_to(TrainingState.FAILURE, message=error[:200])
        except ValueError:
            pass
        job.error = error[:1000]
        job.finished_at = finished_at
        await self._job_repo.update_finished_at(job.id, finished_at, TrainingState.FAILURE)
        await self._job_repo.update_state(
            job.id, TrainingState.FAILURE, progress=job.progress, message=error[:200]
        )
```

- ✅ 状态机非法转移自动拒绝

## 九、风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 现有测试回归 | 高 | 保留旧 API happy path 测试, 逐 Service 迁移 |
| Celery 任务中断 | 中 | task name 保留, 兼容层 fallback |
| 性能下降 (Service 抽象开销) | 低 | 异步 + 缓存热点 |
| 工期超期 | 中 | 分阶段交付, 每阶段可独立合并 |
| 多人协作冲突 | 中 | 严格按文件划分, 增量 PR |
