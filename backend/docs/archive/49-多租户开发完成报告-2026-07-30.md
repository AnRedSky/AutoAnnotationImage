## 四、多租户架构图

```
请求 → TenantMiddleware → JWT decode → TenantContext.set(tenant_id)
                                            ↓
ORM query → do_orm_execute event → if tid != None:
    SELECT ... WHERE tenant_id = :tid     ← 自动注入
                                            ↓
super_admin (tid=None) → 跳过过滤, 看全部数据
```

### 数据模型

```
tenant (1) ─── (N) user
  │                  │
  │                  ├── user_tenant_role (per-tenant 角色)
  │                  │
  ├── (N) dataset ──┤
  │         │        │
  │         ├── dataset_membership (per-dataset 共享)
  │         │
  ├── (N) model_version
  ├── (N) training_jobs
  └── (N) annotation_log
       └── audit_log (通用审计)
```

### 角色体系

| 角色 | 范围 | 权限 |
|---|---|---|
| super_admin | 全局 | 管理所有 tenant + 用户 |
| admin | tenant | 管理本 tenant 用户 + 看全部 dataset |
| annotator | dataset | 标注 assigned dataset |
| viewer | dataset | 只读 assigned dataset |
